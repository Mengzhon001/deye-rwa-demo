# Deye RWA public website

The main branch contains application source. This branch serves the public homepage, bilingual documentation, reviewed contract package and key-free operating manuals. Launch App opens one application with three environments: the private demonstration, the original Base Sepolia product, and Local Oracle on Sepolia. The two Base Sepolia environments share Chain ID 84532 and wallet test-token balances, but have separate products and sign-in sessions.

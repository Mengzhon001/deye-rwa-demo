# 源码交接范围

## 版本与用途

本仓库从项目工作目录整理，于 2026 年 10 月 27 日发布最新源码和双语手册，采用单独建立的 Git 历史。它提供同事安装、理解和继续开发系统所需的源码及说明，不是现有远程演示环境的数据备份。

## 纳入内容

交接包含自有合约、合约测试及部署代码，电站适配器、预测和估值模型，业务服务、钱包鉴权和交易恢复，四角色前端、公开首页与双语文档，以及 Docker、RPC 网关、Blockscout 配置和可重复使用的测试工具。旧版场景保留以支持回归。

根目录增加了安装说明、系统结构、开发测试和可选运维说明。配置模板不包含真实凭证。初始化生成新的本地钱包、数据库密码和浏览器密钥，公开静态发布工具需要显式指定目标仓库。

本地 Compose 使用独立的项目名。备份与恢复工具限定查找本项目的数据卷，避免同一台机器上运行多个演示时选中其他项目的数据。

## 排除内容

原工作目录的 Git 历史、运行状态、钱包密钥、助记词、环境文件、真实 API 凭证、客户原始证据、内部往来材料、研究草稿、浏览器配置、内部原始截图和录像不进入本仓库。经过审查且不含私钥的手册及操作配图纳入 `docs/manual/`。含测试私钥的内部产品说明书也没有复制。工作目录中的临时探测脚本和一次性迁移脚本不作为交接入口。

编译产物、依赖目录和自动生成的公开源码包由安装及构建命令重新生成，不作为源码提交。源码文件清单和 SHA-256 摘要记录在 `source-manifest.json`，用于核对本次交接快照。

## 配置与后续协作

需要连接真实电站时，由有权限的人员另行配置 API 访问。需要查看既有链状态时，使用该环境的 RPC、浏览器和角色账户。新克隆仓库生成的本地账户不能替代既有环境中的授权钱包。

当前公开仓库为 `Mengzhon001/deye-rwa-demo`。`main` 分支保存整理后的源码和双语手册，`gh-pages` 分支保存网站构建产物及公开手册下载。Pages 继续从 `gh-pages` 构建，运行数据与私密配置均不进入任一分支。

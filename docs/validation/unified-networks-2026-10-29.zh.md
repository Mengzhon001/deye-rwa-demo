# 统一网络入口验证记录

本次更新为私有演示链和 Base Sepolia 提供同一个 HTTPS 业务入口。两套后端继续使用原有数据目录、合约和角色配置。新增网关只提供静态页面和固定路径代理，不提供签名、部署、重置或链管理能力。原有业务记录没有迁移或清空。

## 测试结果

六个配置的业务账户分别在两条链上完成签名登录，并读取对应链的业务状态。测试核对了登录消息中的实际网站域名、角色和 Chain ID，也验证了产品合约地址不同。使用私链会话访问 Base Sepolia 被拒绝，没有网络路径的身份请求被拒绝。

隐藏浏览器中的真实 Rabby 0.94.11 完成了 Base Sepolia、私有演示链、Base Sepolia 的往返切换。每次切换均重新签名登录，返回 Base 后仍显示原产品和 20 USDC 的测试钱包余额。随后通过业务页面完成 1 USDC 认购、刷新恢复和全额退款，测试钱包的 USDC 恢复到操作前金额。测试没有对私链提交业务交易，也没有重置或推进任何一条链。

浏览器专项检查覆盖了拒绝钱包切换、存在待确认操作、目标服务不可用、中英文网络说明和移动端窗口。拒绝切换及目标服务失败均保留原网络。待确认操作保留在其所属链，不会在另一条链重新提交。检查中修复了网络窗口居中以及英文提示的文本替换问题。

代理测试验证了请求体原样转发、固定上游地址、实际 Origin、会话 Cookie 的链隔离、限定公开接口的 CORS 和未带网络路径的业务请求拦截。现有 38 项界面流程测试和 29 项引导测试通过。

首页的原生下拉框已替换为带网络图标的圆角按钮和自定义浮层。浮层显示当前网络、两条链的用途以及切换不会转移资金的说明。界面交互参考了 Aave 的图标化选择和浮层列表，配色沿用本站的深色与青绿色设计。检查覆盖键盘方向键、Enter、Escape、点击外部关闭、焦点恢复、手机视口和两条链的应用入口。选择网络只刷新统计，不会重新挂载首页动画。

## 登录后的数据加载反馈

真实 Rabby 测试确认，Base Sepolia 登录签名已经验证后，产品、余额和交易记录仍可能需要约十秒才能返回。应用现在会立即显示已登录的钱包、加载动画和正在查询的网络，不再继续显示未登录入口。等待八秒后会提示网络响应较慢，四十五秒仍未完成时会提供重试入口。数据查询失败不会要求重复签名，但会话确实失效时仍须重新登录。

新增隐藏浏览器检查覆盖了首次签名、慢响应、刷新恢复、中英文切换、手机布局、查询超时、失败重试、重复点击和加载途中切换钱包。受控延迟和失败由浏览器模拟，身份验证使用真实签名及后端会话。另用真实 Rabby 扩展检查了公网 Base Sepolia 登录和刷新恢复，均能先显示加载状态，再进入工作台。这些检查只进行登录和读取，没有提交业务交易或重置任何场景。

## 统一入口的引导资源修复

统一入口曾遗漏 `/guidance-driver.js` 和 `/guidance-driver.css` 的静态文件映射，导致已登录用户点击“定位操作”后收到资源加载失败提示。这两个地址现在均提供本地固定版本的 Driver.js 文件。加载器会同时核对脚本与样式的加载结果，失败后清理资源并允许重试，同时用边框标出已经找到的业务控件。

网关回归检查覆盖了这两个资源的 GET、HEAD 和内容类型，并继续验证网络、会话及来源隔离。公网浏览器检查分别验证了两条链的投资资格申请定位、中英文显示、重复定位，以及脚本和样式加载失败后的恢复。资格状态仅在浏览器测试响应中调整，未改变真实资格或提交申请。

真实 Rabby 扩展另行验证了公网 Base Sepolia 页面，依次高亮现金流时间轴、认购金额输入框和认购按钮。两个资源均返回 200，页面没有出现 JavaScript 异常，测试没有提交认购交易。

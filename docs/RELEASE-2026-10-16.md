# 2026年10月16日发布记录

本次版本将四角色动态引导、认购追加、累计订单审核和V5月度分配更新到公网测试环境。原来的业主、中介和两位受托人地址保持不变。新版体验产品通过正常合约部署和源码验证产生，没有用修改节点代码的方法冒充升级交易。

公网投资者大厅保留一个可以直接认购的体验产品，另有用于完整发行演练的V5草稿。旧体验产品在确认认购款和份额均为零后，由中介签署终止并返还凭证，再从正常产品列表中归档。旧合约和交易仍可查询。测试链未被清空，旧业务记录和证据留有本地备份。

旧Quick Tunnel域名已失效。本次替换了应用、RPC和区块链浏览器地址，并更新GitHub Pages配置。账户地址和Chain ID 20261008不变，钱包需要采用当前首页提供的RPC。Rabby通过本次实际签名检查，MetaMask没有列为本次已验证钱包。

## 验证结果

独立链上的真实Rabby演练从空白申请开始，完成四角色签署、入池、募集结算及连续两个月分配和领取。39项操作证据覆盖35笔链上交易。受托尚未批准本期估值时，引导保留审批任务。新分配确实产生可领取金额后，才交接至投资者。已领取的历史金额不会再产生当前领取任务。电站观测时间在财务时间推进后保持不变。

公网六个角色账户分别完成真实Rabby登录，包含两位投资者和两位受托人。公网登录检查没有提交投资、领取或时间推进交易。新版产品的合约源码与运行代码对应，钱包入口、受限RPC、CORS和公开只读接口检查通过。中英文文档的26个页面、深链接、刷新、源代码下载及移动端入口检查通过。

整理后的源码在独立目录安装依赖并完成编译。模型测试、业务生命周期和重估恢复测试、引导测试、两种合约周期的目录测试，以及旧合约回归检查通过。合约回归中的一项外部分叉测试因缺少指定分叉环境而保持跳过，没有将其记录为通过。公开合约源码包独立安装并通过16项测试。

版本检查发现并修复了产品列表未读取V5分配周期的问题。重复准备录像环境时会重新生成基础设施凭证的问题也已修复，相关检查现已通过。

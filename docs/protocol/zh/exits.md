# 转让、赎回与到期

份额在结算后锁定六个日历月。当前合约限制普通 ERC-20 直接转账，防止绕过资格、锁定期及对价结算要求。退出通过协议提供的转让或赎回流程进行。

## 点对点转让

买卖双方协商份额数量、mUSDC 对价和有效期。买方需具备资格、完成支付授权并确认交易，卖方随后通过合约原子交换份额与 mUSDC。任一支付条件失败时，整笔交换回滚。

NAV 是价格参考而非保证成交价。对价相对参考净值偏离超过 10% 时，需要中介审核对应交易摘要。批准绑定参与者、份额、金额、期限和 nonce，不能复用于不同交易。

## 季度赎回

投资者在窗口截止前提出申请，至少提前 30 天通知。请求份额进入托管，但未支付前不销毁，仍享有按快照宣告的分配权。成交价使用处理日有效 NAV，且已宣告分配已作为负债扣除，不重复支付。

```text
窗口可支付上限 = min(可用赎回现金, 资产池 NAV × 5%)
```

合资格请求按比例成交，整数份额取整后剩余部分顺延。现金不足时不会偷偷使用新认购资金补足。未成交部分可在下次截止前取消，已到截止后的请求按窗口规则处理。错过处理窗口时由中介执行顺延流程。

## 到期清算

五年收益权到期后，剩余设备价值不进入池子，未来收益权估值归零。应收款、费用和负债必须先处理完毕，再关闭产品并按剩余经济份额宣告最终现金分配。产品关闭不意味着投资者必然拿回最初投入的金额。

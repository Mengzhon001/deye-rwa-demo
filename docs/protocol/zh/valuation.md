# 预测、业主电费与收益权估值

新协议采用“业主支付的光伏电费＋合格上网售电收入”的现金流模型。业主保留设备所有权，出售约定期限内的收益权，在募集成功结算时收到购买款，随后按月支付自用光伏电费。新协议默认将扣除约定站点费用后的净收入全部归集到 RWA，期限为结算后 60 个月。

业主的电费折扣与收益权比例是两个独立参数。默认业主按电网购电价的 80% 支付自用光伏电费，而 RWA 默认取得合计净收入的 100%。计算时不会把 80% 再作为收益权比例扣一次。两项参数均须在报价、审核和签约前确定。

## 三种估值基线

三种方法共用下文的业主电费、售电收入、成本及折现公式。它们改变的是预测发电量或上网分配比例，不改变已经签署的收益权经济条款。

| 方法 | 预测发电量 | 预测上网量与审核重点 |
| --- | --- | --- |
| 长期历史季节性 | 最多 36 个完整月的同月历史发电均值 | 使用合格历史样本的上网比例；样本不足或失衡时标记暂定并审核。 |
| 近期上网比例 | 仍使用长期历史同月发电均值 | 使用采集日前 7 至 30 个合格完整日的上网比例；近期电量不平衡时不可选。 |
| PVGIS 辐照气象基线 | 使用 2019—2023 年历史气象模拟的逐小时功率，按已记录或明确标注为暂定的电站参数换算 | 上网比例仍来自德业合格历史样本；参数状态、完整小时记录及来源摘要须随报告披露。 |

截至 2026 年 11 月 12 日，三套业务环境均已加入第三种基线。上海电站可以使用下述**暂定演示参数**载入 PVGIS 逐小时资料，进行新报价的试算与审批；参数状态在页面和报告中保持“演示估计”，不得称为德业确认的实装设计。已签协议及已发布产品不会自动重估。

## 历史数据如何变成未来电量

模型使用估值截点之前最多 36 个月的完整历史。相同日历月份的样本取均值，例如未来八月使用已有完整八月的均值。缺少某个月份时使用可用历史均值并标记覆盖不足。至少 12 个完整月及完整季节覆盖才支持完整历史基线。短样本、缺测字段和统计差异需要明确审核。

```text
预测发电量 G = 同日历月历史发电量均值
             × (1 − 年衰减率)^(已过月数/12) × 可用率 × 当期剩余比例
预测上网量 E = 同日历月历史发电量均值 × 合格样本上网比例 × 相同调整系数
合格光伏上网量 X = E，要求 0 ≤ E ≤ G
可计费自用光伏量 S = max(0, G − X) × 交付系数
```

默认年衰减为 0.7%，可用率为 98%，非上网光伏交付系数为 90%。这些都是可调整的演示假设。交付系数用于对储能损耗、存量变化及其他未交付部分作明确折减，不能替代结算表计，也不是经实测校准的效率。当前没有经确认的光伏自用计量字段，因此新模型报告始终标为暂定，并要求受托人明确接受后才能批准。

不直接把用电量减购电量当作光伏自用量，因为储能可能由电网充电。上网超过同期发电量时，该样本不能用来推定光伏自用量。近期比例方法会被禁用；历史预测排除不平衡的上网样本，使用同月合格样本的发电、上网总量比例分配预测发电量。没有合格样本时，明确使用审核后的演示假设比例，并保留暂定标识。原始 API 读数不会被改写。模型不会同时把同一份电量计为自用和上网。

若近期完整日的上网比例与历史明显不同，需要记录口径核对和基线选择依据。经审核的近期情景使用历史季节性发电量乘以近期完整日上网比例，不把单日收益直接乘以五年天数。前两种基线方法以每期起始的 UTC 月份选取季节样本，跨月服务期尚未按日拆分；下述 PVGIS 方法则按各自然月的实际覆盖时间计算。

## 第三种基线：PVGIS 辐照气象模拟

第三种估值方法采用欧盟联合研究中心 PVGIS 5.3 的 ERA5 历史气象数据。PVGIS 根据辐照、温度等气象资料和指定组件设计，模拟 2019—2023 年每小时一座 1 kWp 电站的功率。系统先检查五年逐小时记录和请求参数是否完整一致，再按 UTC 自然月计算单位装机容量的平均发电量。该方法使用历史气象形成的季节性基线，并不预报未来某个月的实际日照，也不把模拟发电量称为德业电表读数。

中介机构必须记录本电站坐标、直流侧额定容量、组件倾角、方位角和额外首年系统损耗各自的依据，并区分 API 记录值与暂定假设。PVGIS 方位角以正南为 0°，负值表示偏东。服务端以 `peakpower=1`、`loss=0` 获取 PVGIS 功率，随后按下式换算，因此额外损耗只扣一次。附件 Notebook 的其他代表城市和 1 MWp 仅为示例，不属于本电站资料。

### 上海电站暂定演示参数

| 输入 | 本次取值 | 来源与确定程度 |
| --- | ---: | --- |
| 坐标 | 北纬 31.173725°，东经 121.48858° | 德业 API 录制回放中的 `locationLat`、`locationLng`；尚未以现场测量独立核实。 |
| 直流侧容量代理 | 40 kWp | API 的 `installedCapacity` 经单位映射后为 40 kW。接口未说明其为 DC 还是 AC 额定值，本次暂以相同数值作 DC kWp 代理。 |
| 固定组件倾角 | 30° | PVGIS 在上述坐标给出的模型最优固定安装角度，**不是**电站实测倾角。 |
| 组件方位角 | −2° | 同一 PVGIS 最优角度计算给出的朝向，接近正南且略偏东，**不是**电站实测朝向。 |
| 额外首年系统损耗 | 14% | 用于演示的统一情景假设，并非德业提供的损耗测试结果；PVGIS 逐小时请求本身设 `loss=0`，避免重复扣减。 |

这些参数对应的回放电站观测时间为 2026 年 9 月 24 日（中国标准时间）。PVGIS 5.3 ERA5 对 2019—2023 年的完整 43,824 个小时返回年均 **1,465.70 kWh/kWp** 的无额外损耗模拟值。按 40 kWp、14% 额外损耗和现有模型的 98% 可用率计算，首年约为 **49,411.78 kWh**；这只是气象与设计情景的计算结果，既不是德业历史电表读数，也不证明设备的实际 DC 铭牌容量。原始 PVGIS 响应摘要为 `c2779962f6bc066525f9556b05ade82bcba9e8495c6eeb30c1cf31f20eef067c`。实际报价仍需说明上网分配、电价与费用假设，并经中介及受托人审批。[PVGIS 官方 API 参数说明](https://joint-research-centre.ec.europa.eu/photovoltaic-geographical-information-system-pvgis/using-pvgis-5/api-non-interactive-service_en)提供了倾角、方位角与损耗的定义。

```text
服务期模拟发电量 = Σ[所覆盖自然月的 PVGIS 平均 kWh/kWp × 覆盖天数 / 当月天数]
                 × 电站直流侧 kWp × (1 − 额外首年损耗率)
                 × 可用率 × (1 − 年衰减率)^(已过月数/12)
预测上网量 = 服务期模拟发电量 × 德业历史合格样本的同季节上网比例
```

跨月服务期按各自然月的实际覆盖时间计算；估值时已经完成的服务时间不再计入未来发电量。业主自用、电费、售电收入、成本和折现继续使用下方的共同现金流公式。历史上网比例仍来自德业观测，电价、汇率和可用率等仍是独立审核的假设。PVGIS 不提供业主未来用电需求，也不能证明电网已经支付售电款。

原始 PVGIS 响应保存在服务端，并以 SHA-256 摘要、数据年份、坐标和设计参数写入估值凭证。中介复核后才能提交报价，受托管理人仍须批准。更新辐照基线不会自动改写已签协议或旧报价；若估值引用的基线摘要与当前记录不符，系统要求重新估值。接口不可用、小时记录缺失或设计参数不匹配时不会以代表城市或旧缓存冒充本电站数据。[PVGIS 官方 API 说明](https://joint-research-centre.ec.europa.eu/photovoltaic-geographical-information-system-pvgis/using-pvgis-5/api-non-interactive-service_en)解释了 `seriescalc` 的请求参数。

## 每月电费和项目现金流如何计算

购电价与售电价分别配置。购电价指可按电量比较的零售电价，售电价指合格上网电量适用的电价。各自可以配置 60 个月的价格计划，或者用基础电价与年增长率生成计划。模型使用月度价格，不假设月度电量足以精确还原分时电价账单。

```text
业主支付给项目的电费 H = S × 电网购电价 B × 业主支付比例 d
售电收入 F = X × 上网售电价 T
项目毛现金流 = H + F
受让现金流 C = max(0, H + F − 约定站点费用) × 归集比例 × 汇率
```

新协议的 d 默认 80%，归集比例默认 100%。汇率方向为每单位电站本币对应多少 USDC。站点维护、保险、税费、收款和更换支出须明确付款责任。仅扣除约定由项目收益承担的费用，业主自付费用不在这里重复扣除。收入不足以覆盖站点费用时，报告提示资金缺口；受让现金流为零不意味着缺口已经有人支付。

业主实际向电网购买的电量仍由业主付给电网，这笔钱不是 RWA 收入，也不从 RWA 中重复扣除。平台与中介合计年费、资产池储备和按期分配在资金池层另算，不能重复列为站点费用。

## 为什么业主的电费低于全部从电网购买

比较必须针对同样的供电量和同一电价。设实际从电网购买的电量为 I，不含固定费用的电量账单为：

```text
全部向电网购买的费用 = (S + I) × B
出售收益权后的电量费用 = S × B × d + I × B
相同电量的费用差额 = S × B × (1 − d)
```

只要 S 和 B 大于零，且 d 小于 100%，上述相同电量费用就会下降。20% 折扣仅作用于自用光伏电量对应的费用，不等于家庭全部电费下降 20%。固定费、需量费、税费和其他业主自付成本不在该比较内。

如果历史购电量缺失，页面只比较自用光伏部分，完整账单显示不可用，不把购电量当零。历史购电量可用时，以同季节历史均值展示示意账单，不将其描述为未来负荷的确定预测。

这一比较的基准是全电网供电，不是出售前已经拥有光伏时的免费自用。出售后，业主新增按月付费义务，并放弃协议内的售电现金流；对应补偿是结算时收到的收益权购买款。是否值得出售，应结合该购买款、付费义务、设备维护责任和保留权益一起判断。

## 一个完整的月度计算示例

以下仅为算术示例，不是当前电站的实际账单。假设某月发电 1,000 kWh、上网 400 kWh、另向电网购电 200 kWh。交付系数为 90%，购电价为 0.60 元/kWh，售电价为 0.35 元/kWh，业主支付比例为 80%。

| 计算项目 | 计算过程 | 结果 |
|---|---|---|
| 可计费自用光伏量 | (1,000 − 400) × 90% | 540 kWh |
| 相同光伏电量按电网价购买 | 540 × 0.60 | 324 元 |
| 业主向项目付费 | 324 × 80% | 259.20 元 |
| 业主另付电网 | 200 × 0.60 | 120 元 |
| 全电网方案的电量费用 | (540 + 200) × 0.60 | 444 元 |
| 出售后的电量费用 | 259.20 + 120 | 379.20 元 |
| 相同电量少付的费用 | 444 − 379.20 | 64.80 元 |
| 上网收入 | 400 × 0.35 | 140 元 |
| 项目毛现金流 | 259.20 + 140 | 399.20 元 |
| 扣除站点费用后的净收入 | 399.20 − 100 | 299.20 元 |
| 100% 归集并换汇 | 299.20 × 0.14 | 41.888 USDC |

## 如何折现成今天的报价

每期电量先对应一个服务期，预计回款日为服务期末加约定延迟，默认延迟一个月。每期现金流按实际距估值日的年数分别折现，再求和，不能把未折现的 60 个月收入总额当作报价。

```text
第 m 期现值 = C_m ÷ (1 + 年折现率)^((预计回款时间 − 估值时间) / 365.25天)
收益权折现价值 = 所有剩余服务期的现值之和
```

基准年折现率为 10%，另展示 6% 和 14% 的敏感性。以示例中的 41.888 USDC 为例，如果恰好在 365.25 天后收到，则按 10% 折现后的现值为 38.08 USDC。实际页面使用每期的真实日期间隔。上下行情景将受让现金流缩放至 80% 和 110%，不是经校准的概率情景。

### 折现率的含义和确定方法

折现率表示持有这项有限期收益权所要求的回报，用于把**预计未来收到的净现金流**换算成估值日的价格。折现率升高，同一组预测现金流的现值就下降。它与业主按电网价 80% 缴费的优惠比例、结算时自动留存 10% 现金的规则、投资者最终实现的 IRR 均不是同一个参数。当前 10% 是尚未经过可比交易和实际回款充分校准的演示定价假设；6% 和 14% 仅显示估值对利率变化的敏感程度，并不表示收益落在这个区间的概率。以上述一年后收到的 41.888 USDC 为例，6%、10%、14% 下的现值依次约为 39.52、38.08、36.74 USDC。

一个可审计的报价可以从同币种、相近现金流期限的低风险利率开始，再根据收益权合同、付款人和电站的风险确定额外要求的回报：

```text
收益权要求回报率 ≈ 同币种期限匹配的基准利率
                  + 业主缴费与售电回款风险溢价
                  + 发电、运营与数据风险溢价
                  + 合同执行、流动性和其他未覆盖风险溢价
```

这是一套**校准框架，不是能自动算出唯一正确百分比的公式**。各项溢价须依据合同保障、业主付款记录、电网结算证据、设备运行、数据质量、退出限制及可比交易说明。若预测现金流已经扣除了某期的预计欠费、发电损失或费用，就不能再把同一预计损失完整加入折现率。不同风险可能相关，也不能机械相加。旧版 [Centrifuge Tinlake 的 NAV 说明](https://developer.centrifuge.io/developer/legacy/tinlake/)分别处理预计违约损失和折现，其文中的 3% 只是教学算例；[现行 Centrifuge 文档](https://docs.centrifuge.io/user/manager/nav/)要求按各产品自己的估值政策确定 NAV，没有协议统一折现率。

**币种必须一致。** 当前模型将人民币计价的业主电费、售电收入和站点费用按报告中的固定换算系数转换为 USDC，再以单一年利率折现。因此，该利率应解释为对 **USDC 计价收益权现金流**的要求回报；美元国债收益率可作低风险参考，但 USDC、跨币种结算和合同风险仍需另行评估。固定汇率只是演示假设，不能证明未来人民币兑美元汇率不变。另一种自洽做法是在人民币中预测和折现现金流，然后于估值日换算现值；不能对已换算为 USDC 的现金流直接套用人民币国债利率。这里的“名义”指现金流和利率均未剔除通胀；计算按 `(1 + r)^(实际天数/365.25)` 复利折现，并非简单把月利率乘以 12。电价及成本预测若含名义增长，折现率也须采用名义口径；期限、税费和现金流日期同样须一致。

公开资料只能提供参照，不能直接替换本电站的审批。2026 年 11 月 10 日美国国债五年期收益率为 4.81%，11 月 12 日中债五年期国债收益率为 1.329%；若仅做算术相减，10% 分别隐含 5.19 和 8.67 个百分点的剩余差额，但两种币种口径不能混用，这些差额也不证明风险溢价合理。[美国财政部收益率表](https://home.treasury.gov/resource-center/data-chart-center/interest-rates/TextView?field_tdr_date_value=2026&type=daily_treasury_yield_curve)与[中债收益率曲线](https://yield.chinabond.com.cn/cbweb-pbc-web/pbc/more?locale=en_US)会随日期变化。作为行业背景，[IEA 的 2019 年中国大型光伏项目样本](https://www.iea.org/articles/the-cost-of-capital-in-clean-energy-transitions)显示，受收入保障项目的税后名义加权资本成本为 4.4%–5.4%，承担市场售电风险的项目为 6.4%–6.9%。这些是大型电站融资成本，既非本项目 2026 年的市场报价，也非本收益权的适用折现率。

中介编制报价时应在估值报告中记录估值币种、基准曲线及日期、每项溢价的证据、已在现金流中扣除的预期损失、折现口径和 6%／10%／14% 的价格对比；受托管理人复核后批准。获得足够的实际缴费、售电回款和交易价格资料后，再校准产品专属折现率。利率调整只作用于新的报价或重新估值，不会静默改变已签协议。

## 旧协议、审核和更新

常规合并收入模型标识为 `household-export.2`，PVGIS 辐照基线模型标识为 `pvgis-era5-irradiance.1`；两者的 `revenueModel` 均为 `household-export`。旧记录缺少该字段时仍解释为 `export-only`，不会因软件升级而向原业主新增付费义务。未签约的报价可以选择新基线后重新报价，受托审批和业主接受必须重新执行。已签约或已入池协议保留原条款；如需改变已签经济条款，应使用新协议和产品。

输入证据摘要、全部财务假设、模型版本、逐期计算、估值日和有效期写入报告摘要，协议签名同时绑定假设摘要。估值按月更新，交易前和重大变化后重新核对。完成的服务期转为应收款或现金，不能继续计入剩余收益权。

预计投资者净 IRR 是资金投入、按期分配和到期现金的计算结果，不等于 10% 估值折现率。投资者时间轴和费用顺序详见[回款、费用与现金分配](/docs/zh/accounting)。

# 协议概览

Deye RWA 将光伏电站约定期限内的业主电费与售电收益权纳入资产池，并用链上记录连接业主、中介机构、投资者和受托管理人。当前系统是本地演示，链上支付使用测试代币，不能作为实际证券发行或真实资金结算系统使用。

## 投资对象是什么

业主保留光伏与储能设备的所有权。新协议约定业主按折扣价支付自用光伏电费，并将这笔电费与合资格售电收入合并，扣除约定站点费用后默认将100%净收入归集至RWA。默认业主支付电网电量电价的80%，期限为产品结算后五年。电费支付比例和收益归集比例是两个独立参数。签署时冻结比例、期限、可扣除费用和收款责任。到期后的设备价值不属于资产池。

系统有两层凭证。每个电站对应一个电站 NFT，资产池持有其约定收益权的凭证。投资者在募集成功结算后取得 DRS 份额，按份额参与现金分配和资产池剩余净值。

## 什么决定投资收益

收益取决于上网电量、电价、费用、收款情况、发行价格和退出条件。分配现金后，有限期收益权的剩余价值可能下降。应同时查看预计净年化收益、已收分配、剩余净值和总回报，不应把现金分配率直接当成年化收益。

系统没有固定票息保证，也没有自动偿还原始本金的安排。预测值是估计，模拟回款是演示数据，二者均不能证明业主已经收到真实电费。

## 三个入口

首页介绍协议并展示经过筛选的当前场景统计。Documentation 无需钱包即可阅读。点击 Launch App 后先选择业务角色，再连接钱包并签名登录。

产品大厅只展示已经发布募集的产品。合约已经部署并不意味着产品已经发行。草稿不会进入大厅，募集中与已结算存续中的产品有不同状态，失败和关闭的产品在历史筛选中查看。

## 阅读顺序

先阅读角色与权限，再了解数据、估值和业务流程。准备演示时，按本地部署与操作手册执行。开发者可以阅读接口、合约和源码下载章节。

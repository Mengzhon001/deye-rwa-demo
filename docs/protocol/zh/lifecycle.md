# 从申请到发行

申请和文档审核首先在后端进行。链上操作从中介铸造电站凭证开始，随后分别由业主和中介完成托管授权与入池。一次按钮不会替三个角色完成签名。

## 申请与协议

业主选择电站并提交收益权申请。中介可以要求补充、拒绝或通过资料审核。通过资料审核不等于报价已批准。中介根据电站证据生成报价，受托人审核后，业主接受约定价格并签署绑定电站、比例、期限、链和产品的协议。

电价、费用和基线若发生重大变化，应重新评估并取得相应批准及接受，不能沿用旧报价强行发行。

## 三步入池

<div class="diagram"><span>中介铸造 NFT 给业主</span> → <span>业主授权资产池托管</span> → <span>中介提交收益权入池</span></div>

NFT 和协议摘要记录站点身份及约定。入池建立托管和收购款记录，不会立即铸造投资者份额。设备控制和设备产权不因此转移。

## 估值与发布

中介准备资产池估值并提交交易。受托人通过独立交易批准后，中介核对募集目标、发行条件、预计净 IRR 和现金保留要求，再发布募集条款。链上出现 ProductPublished 后才进入产品大厅。

当前版本每个场景只发行一个产品。已发布条款不能随意改动，不能把未获重新接受的新条款用于旧订单。若需要不同的条款，必须重新走受支持的业务流程，或在演示中建立新场景。

## 募集与份额发行是两个阶段

产品发布后可以接受合资格投资者认购。只有订单审核、资金门槛与收购款要求全部满足，结算交易才能支付业主并铸造 DRS。ProductSettled 才代表份额发行完成。募集失败则退款，不发行份额。

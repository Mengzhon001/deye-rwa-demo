# 服务事件与受托处置

普通发电不足或模型预测偏差不会自动构成业主违约。服务事件针对未按约归集回款、转移收款、违反约定义务或持续运营事故等需要核查的情况。

## 发起与证据

中介建立事件，记录证据摘要和拟变更的演示收款地址。案件建立时固定经济持仓快照。后续份额转让不能扩大或转移该案件的投票权，每个快照持有人只能按规则支持一次。

## 门槛与双受托批准

快照权重达到 30% 才满足启动门槛。此后需要两个不同受托地址分别批准，中介不能作为受托人完成自审，同一个受托人不能计作两次批准。

执行结果是合约内的演示收款方记录发生变化，并留下事件和交易回执。它不会远程控制逆变器，不会修改真实电网结算账户或银行账户，也不能替代线下协议执行。

## 页面核对

查看事件的快照总量、已支持权重、两位受托人批准状态和最终交易。链上确认与 Blockscout 索引分别展示，浏览器索引慢不等于事件未执行。

# 电站数据与证据

Deye 适配器在服务端调用电站发现、详情、设备、最新读数、历史电量及告警接口。区域、AppId、AppSecret 和账户凭据通过服务端环境配置读取，不进入浏览器。

## 电量口径

发电量、上网电量、购电量、自用电量和电池充放电量是不同指标。功率用 kW，累计电量用 kWh；MWh 需要乘以 1,000 才能参与 kWh 计算。设备数据由逆变器统计，电站数据可能由云端汇总，不应在没有核对统计口径时互相替代或重复相加。

适配器保留站点时区，并规范时间窗、分页、单位与缺失值。没有提供的读数显示为空，不默认补零。日期不完整的月份不能当成完整月度历史。财务时间推进不会修改遥测的实际采集时间。

## 三种数据模式

| 模式 | 含义 |
| --- | --- |
| live | 从真实 API 读取并保存的观测，需查看采集时间，不能把缓存当成实时刷新。 |
| replay | 读取已经保存的 API 证据，可以复现既有计算。 |
| synthetic | 明确标记的合成样本，仅供本地流程测试。 |

真实 API 请求失败时不会自动切换合成样本。接入电站数量表示已有遥测记录，入池电站数量表示收益权已完成链上入池；这两个数值可以不同。

## 最新监控与估值证据

远程测试环境每 15 分钟通过真实 API 更新监控。电站详情中的“更新 API 数据”也可以请求同步，所有角色共用一分钟的请求冷却时间。页面分别显示采集时间和设备读数时间。`ALL_OFFLINE` 表示该次响应中的全部离线状态，`PARTIAL_OFFLINE` 表示部分离线；旧回放记录中的状态不代表当前通讯情况。同步失败时会显示错误，并保留上一次成功记录及其原时间，不会把失败当成发电量为零。

监控更新不会覆盖已申请产品中的估值证据。新申请采用当时最新的采集证据，随后由中介和受托人审核；已有报价需要变更基线时，应通过重新评估流程处理。这样既能查看最新运行情况，也能复现当初报价的输入。

## 身份与证据

电站 ID 根据数据中心区域和站点 ID 稳定生成。一个站点可以关联多个设备，但不会因此增发电站 NFT。原始响应与规范化证据保存在后端，估值记录绑定输入证据摘要和模型版本。内容摘要证明引用的内容版本，不证明传感器本身绝对准确。

## 收益数据的边界

目前 Deye 云的收益与电价接口未向本项目开放。仪表盘的电量可来自 API，但电价、费用、汇率及收款回执仍使用明确标记的演示假设。网页上估算的售电收入不是 Deye 官方结算金额，也不能视为已收现金。

若云网页与 API 不一致，应按同一站点、日期、时区、接口路径和字段名核对。尚未解释的云端汇总差异不能用手工调数掩盖。


## 自用电量与电费假设

月度证据另保留API的购电量和用电量，缺失时为null。它们用于核对和账单示意，尚不能证明其中电量的光伏来源。新收益模型的可计费自用量采用发电量减合格上网量后的交付系数估算，并在报告中明确标记。当前不把储能充放电差额直接当作套利收益。购电价和售电价都是独立的演示输入，不是通过未开放的Deye收益接口取得的价格。预测与演示账单共用同一计算规则。业主电费由业主钱包实际支付测试 USDC；只有电网售电回款由独立系统账户模拟，不能代替业主缴费。

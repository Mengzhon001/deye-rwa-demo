# 资格、认购与结算

普通钱包连接后尚未取得认购资格。投资者先在资格页面确认风险与演示声明并提交申请，中介审核并签署链上批准交易后，合约才允许认购。

## 测试资金与支付

水龙头明确发放演示 DETH 和 mUSDC。钱包可用余额与认购托管金额是不同字段，领币不等于下单。mUSDC 使用六位小数，前端金额转换成链上整数后再提交。每次 Demo 重置会产生新代币地址，请使用当前产品的地址。

认购分两步。投资者先授权资产池支出 mUSDC，再签署 subscribe 交易，资金进入认购托管。份额余额在结算前仍为零，这是正确状态。

## 订单审核与退款

新版演示合约 RevenueShareVaultV4 和 V5 不设冷静期。在募集开放、估值与资格有效且额度尚未用尽时，同一个投资者可以多次认购。每次只支付本次输入的新增金额，合约将各次付款累计托管。例如，先认购 100 USDC，再追加 200 USDC 和 300 USDC，累计托管为 600 USDC，钱包实际支付合计也为 600 USDC。

每次追加都会产生新的审核序号，并清除原有批准状态。中介在“产品运营”的“认购订单审核”列表审核最新累计金额，审批须绑定投资者地址、当前序号、金额、发行条款和审核说明摘要。因此，100 USDC 的旧审批不能用于批准追加后的 600 USDC，较早准备但尚未提交的审批交易也不能覆盖新订单。界面保留每次付款及退款的时间、金额和交易链接。

中介选择“不通过并全额退款”时，同一笔交易将全部累计托管款退回原投资者钱包。投资者主动取消认购时，也退回全部累计金额，当前版本不提供只撤销某一次追加的功能。审核通过并不立即铸造份额，仍须满足资产池统一结算条件。成功结算后停止一级认购，退出须使用转让或赎回流程。

旧版合约不可原地改写。升级前已有的认购保留在原合约中，原有退款条款继续有效。旧募集若经授权终止，原投资者可全额领取退款。系统会提示原订单入口，但不会自动终止旧募集。旧款不会被自动转移到新产品；投资者应先退款，再选择新版产品重新认购。原交易仍可在 Blockscout 查询。

## 成功结算条件

| 条件 | 说明 |
| --- | --- |
| 募集状态 | 产品已发布，尚未成功结算或失败。 |
| 订单审核 | 所有有效认购均经中介钱包审核通过，投资者资格仍有效，无须等待三天。 |
| 募集门槛 | 已认购金额至少达到募集目标的 70%。 |
| 收购资金 | 留存认购金额 10% 后，仍足以支付全部已签收购价格。 |
| 估值及条款 | 使用获批且有效的估值，并符合固定发行条款。 |

70% 门槛不代表一定能结算。若 70% 的资金不足以支付收购款及储备，仍需更多资金。结算一次性支付收购款，按认购金额和发行价格分配份额，初始认购款的 10% 留作资产池现金。

当前合约的初始发行价格为每份 1 mUSDC，使用六位小数。业务页面的预计投资回报取决于发行价格对应的资金安排，不能通过更改页面数字绕过合约规则。

## 失败与重复操作

未达到条件的募集可以按到期失败路径结束，并由投资者领取退款。结算成功后关闭一级认购，不依赖新投资者资金满足赎回。后台持久化交易意图与幂等键，重复点击不能再次付款或铸币。


私有演示链的资金入口可以发放本链 DETH 和 mUSDC。Base Sepolia 使用 Circle 测试 USDC 和测试 ETH，应用只能打开官方水龙头，不能增发。请核对当前网络和实际使用的钱包地址，另一条链或另一个地址的余额不能用于本次认购。

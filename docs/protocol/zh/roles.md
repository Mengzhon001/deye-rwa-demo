# 角色、钱包与权限

平台按钱包地址识别角色。选择角色只是提出登录请求，不能自行获得管理权限。登录消息绑定域名、地址、链 ID、随机数、有效期和所选角色，后端验证签名和地址配置后签发会话。

## 四种角色

| 角色 | 主要工作 | 权限边界 |
| --- | --- | --- |
| 业主 | 提交申请、补充资料、接受报价、签署协议、授权 NFT 托管，并用本人钱包支付月度 USDC 电费。 | 不能自行审批估值、发布产品或发行份额。 |
| 中介机构 | 审核申请、准备报价与估值、铸造凭证、入池、发行及运营。 | 不能代替业主授权，也不能代替受托人批准估值。 |
| 投资者 | 申请资格、认购和退款、领取分配、转让、申请赎回及支持服务事件。 | 资格必须经中介审批并写入合约，普通钱包不能调用管理方法。 |
| 受托管理人 | 审核报价、批准资产池估值、批准服务事件处置。 | 中介与受托人地址不同；收款方变更需两位不同受托人分别批准。 |

## 登录顺序

点击 Launch App，选择角色，再点击连接钱包并登录。钱包先连接并切换到演示网络，再签署登录消息。登录签名不转移资产，每个后续链上操作仍需单独确认交易。

业主、中介和受托人使用网络配置中指定的钱包。受托人入口可使用两位受托人中的任意一位，平台保留两人的独立身份。普通未绑定的钱包作为投资者进入，但认购资格并不会自动通过。

如果地址不匹配，弹窗显示所需地址并提供切换钱包入口。拒签或取消不会推进业务。账户切换、网络变化、断开连接和会话过期都会要求重新登录。

## 系统账户

部署账户、水龙头及单独模拟电网售电回款的账户负责本地基础服务。它们不能代签业主、中介或受托人的业务。正式用户的私钥不保存在后端。自动化测试使用独立的本地钱包，测试密钥不进入网页或源码包。

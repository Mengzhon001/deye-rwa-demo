# 风险、限制与故障排查

本平台展示可验证的业务流程，但尚未构成可直接上线的金融基础设施。当前支持多个独立测试产品，部署在本地私链，使用演示支付资产。各产品的合约、测试 USDC、投资资格、认购与持仓分别保存。复用电站证据只用于独立测试，不代表可以重复出售真实收益权；生产环境还需要跨产品的权益唯一性和法律登记。合约未经独立审计，访问控制、托管、法律协议、个人信息处理及长期运维仍需在生产部署前专项评估。

## 模型与收款风险

历史季节性不保证未来电量。设备故障、天气、出口策略、电价和收款延迟均可能影响结果。短记录、缺失上网字段和近期基线变化应明确披露。Deye 云收益接口未开放，不能声称本项目复现了官方收益模型。

资产池缺乏现金时不能保证赎回，有限期收益权没有设备残值保护或本金保证。真实权利转让、追索、税费和结算需以最终有效协议及当地要求为准。

## 常见问题

| 问题 | 核对方式 |
| --- | --- |
| 产品大厅为空 | 如果合约仍为 Draft，这是正常情况。中介需要完成入池、估值批准和发布募集。 |
| 钱包一直连接 | 核对 Docker 健康、Chain ID 及钱包中尚未处理的请求。本地使用 RPC 18545，远程使用应用提供的当前 HTTPS RPC。登录时选择已安装的钱包；内嵌浏览器可能没有扩展。 |
| 领币后订单为零 | 查看钱包可用余额。订单只有认购后才增加，DRS 份额只有结算后才增加。 |
| 不能选中介或受托身份 | 使用弹窗提示的配置地址，选择角色本身不会赋予权限。 |
| 报价需重新评估 | 核对基线变化、证据摘要和有效期，由中介重估及受托人审批。不要跳过校验。 |
| 区块浏览器没有交易 | 先查看链上回执，再检查索引服务。确认与索引是两种状态。 |
| 页面无法读取网络 | 首页和文档仍应可读。检查 API 与节点后再连接应用，不能使用伪造统计替代。 |

## 远程演示

另一台电脑的 127.0.0.1 指向它自己，不能访问本机私链。远程使用需要部署可达的网页、过滤 RPC 和浏览器地址，并配置 HTTPS、允许的来源、签名域名及网络 URL。只公开过滤网关，不公开允许管理方法的内部节点。

## 安全反馈

在用于真实资金前，需要完成独立合约审计、威胁建模、权限管理、数据和财务对账、密钥托管、备份演练及法律审查。MIT 开源许可提供使用和审查权利，不构成安全性或投资回报承诺。


## 业主用电计费边界

当前支持业主钱包实际支付测试 USDC 及中介核对确认，但尚无经核验的光伏自用结算表计、生产电费账单、法币扣款渠道或生产催收机制。系统展示的自用量、折扣和电费均为审核后的演示假设，不能直接用于真实收费。月度零售电价未还原固定费、需量费、分时价及完整税费。全电网对比不代表出售收益权比继续免费自用设备更省钱。业主未付电费和售电款未归集均属于回款风险，不能把预计账款当作已收现金。

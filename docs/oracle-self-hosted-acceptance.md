电站凭证、资产池和报告登记合约已在 Blockscout 标记源码验证。Blockscout 对新版账单合约的验证请求返回限流状态，随后该合约通过 [Sourcify 精确字节码匹配](https://repo.sourcify.dev/contracts/full_match/84532/0xFa650D2619452E1763695c780F478bDeA7027D28/)完成独立源码核验。

Oracle 产品目前仍为发行准备状态。只有完成产品结算并到达首个完整自然月的真实截止日后，才能登记可计费报告，并依次验收业主 Circle 测试 USDC 缴费、中介确认、收入入池和投资者分配。历史月份的登记不能替代这项验收，也不证明德业已经为数据提供数字签名。电网售电回款在本环境仍来自单独标注的模拟测试资金。
